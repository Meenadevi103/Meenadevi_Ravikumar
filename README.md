# Portfolio Website click Here--->https://meenadevi103.github.io/Meenadevi_Ravikumar/

A professional portfolio website built with **HTML, CSS, and Bootstrap**.

## Features

- **Responsive Design**: Works seamlessly on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Bootstrap 5**: Utilizes Bootstrap for responsive grid and components
- **Font Awesome Icons**: Beautiful icons for social media and more
- **Google Fonts**: Custom typography with Outfit and Roboto fonts
- **Smooth Scrolling**: Enhanced user experience with smooth page transitions
- **Contact Form**: Integrated contact form using Formspree

## Sections

1. **Hero Section**: Eye-catching introduction with profile image and call-to-action buttons
2. **About**: Personal introduction and CV download
3. **Skills**: Display of technical skills with visual rating system
4. **Projects**: Showcase of portfolio projects with descriptions and links
5. **Contact**: Contact form and social media links

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.3.0
- Font Awesome 6.4.0
- Google Fonts (Outfit & Roboto)

## How to Run

Simply open the `index.html` file in your web browser:

1. **Using a local server** (recommended):
   ```bash
   # If you have Python installed:
   python -m http.server 8000
   
   # If you have Node.js installed:
   npx http-server
   
   # Or use VS Code Live Server extension
   ```
   Then visit `http://localhost:8000` in your browser.

2. **Opening directly**:
   - Double-click `index.html` to open it in your default browser
   - Or right-click and choose "Open with" → Select your browser

## Customization

To customize this portfolio for yourself:

1. **Update Personal Information**:
   - Edit the text content in `index.html`
   - Replace profile images in `/assets/about/`
   - Update social media links

2. **Modify Projects**:
   - Edit the project cards in the Projects section
   - Add your own project images to `/assets/`
   - Update project descriptions, skills, and links

3. **Change Colors**:
   - Modify CSS variables in `style.css` (`:root` section)
   - Customize colors throughout the stylesheet

4. **Add/Remove Skills**:
   - Edit the skills grid in `index.html`
   - Add skill icons to `/assets/`
